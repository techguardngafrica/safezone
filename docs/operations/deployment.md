# Deployment Foundations

Deployment targets are currently documented placeholders (`.github/workflows/ci-main.yml` and `infrastructure/deployment/`).

Planned independent runtime deployments:
- `backend-api` (HTTP API)
- `backend-worker` (BullMQ worker)
- `backend-realtime` (Realtime WebSocket gateway)
- `management-web`, `super-admin`, `public-web` (Next.js)
- `resident-mobile`, `management-mobile`, `security-mobile` (Expo EAS)
